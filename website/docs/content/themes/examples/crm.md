The [Recruiting CRM](/crm) demo is a LiveView built entirely with Essence Themes components: `TextField`, `DropdownMenu`, `Card`, `Avatar`, `Badge`, `ScrollArea`, and `AlertDialog`.

## What it showcases

- App shell layout with icon rail navigation
- Search field with a leading slot icon
- Kanban columns of candidate cards
- Detail overlay via AlertDialog
